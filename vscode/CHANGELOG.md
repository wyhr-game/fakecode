# 更新日志

## 1.1.2

- 新增设置项 `xiaogong.afterFinish`：写完之后「停止」（默认）或「继续播放（循环）」
- 参数面板里多一行「写完」下拉，选完直接生效
- 循环时会在输出里记一行，方便确认不是卡住了

## 0.2.0 — 2026-11-16（重写版）

这一版把引擎换成了「先算事件流，再执行」的结构，界面观感对齐独立软件版。

### 新增

- **虚拟文件系统**：写到哪个文件，资源管理里就出现哪个，写完带内容；
  文件存在内存里，磁盘零写入。停止播放时整个虚拟目录移除。
- **事件流引擎**：`planLines()` 一次性规划整段的 type / wrong / backspace / newline / pause，
  执行层不掺随机，节奏可测可复现。
- **跨文件连续行号**：思考/走神按全局行号触发，播到第 5 个文件也不会突然每行都停顿。
- **可打断的等待**：每 35ms 轮询一次，按下暂停立刻停，不会先打完半行。
- **速度 0.1 ~ 1000×**：
  - 正常速度逐字符写（手感最好）
  - ≥ 20× 自动合并 4 个字符一次写（VS Code IPC 有开销）
  - ≥ 200× 整行一次写，靠动画帧追
- **存档 10 槽**：与独立软件共用 `%APPDATA%\xiaogong\sessions`，两边可以接着播。
- **暂停三选项**：继续 / 退出并保存 / 退出且不保存（QuickPick）。
- **配置**：新增 `xiaogong.virtualExplorer` 开关；`speed` 上限从 5 提到 1000。

### 变更

- 测试从 13 条扩到 18 条，覆盖事件流、跨文件行号、合并逻辑、速度上限保护。
- 大文件裁剪后会在中间留一行 `# … skipped N lines …`，不再静默跳。

### 已知限制

- 只支持 Python
- 虚拟文件系统里的文件是只读的展示，不参与 git
- 老板键没有配置去处时只能关闭所有编辑器
