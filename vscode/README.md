# 魈公引擎 · Xiaogong Engine

> 把代码按人的节奏，重放一遍。

选一个本地代码目录，它会在编辑器里新建一个文档，然后像人一样把那个目录里的代码逐行"写"出来：
有停顿、有打错、有退格、有走神。

**它不生成代码，不修改你的文件，不联网，不提交 git，不保存任何 .py 到磁盘。**

---

## 它不是什么

```
不是 AI 编码工具      —— 它一个字都不会替你写，它只是播放已有的代码
不是录屏软件          —— 屏幕上出现的是真编辑器和真文本
不是对抗监控的工具    —— 不做进程注入、不改系统状态、不伪造活动
不是让你造假绩效的东西 —— 请自己判断使用的场合与边界
```

---

## 安装

```
1. 下载 xiaogong-engine-0.1.0.vsix
2. VS Code → 扩展面板 → 右上角 … → 从 VSIX 安装
3. 或者命令行：code --install-extension xiaogong-engine-0.1.0.vsix
```

---

## 使用

```
1. Ctrl+Shift+P → 搜「魈公引擎」
2. 选「开始（选目录）」
3. 挑一个有 .py 文件的目录
4. 它会打开一个新文档，开始写
5. 想停：Ctrl+Shift+H（老板键），或命令「停止」
```

---

## 命令

| 命令 | 作用 |
|---|---|
| 魈公引擎：开始（选目录） | 选目录并开始播放 |
| 魈公引擎：暂停 / 继续 | 切换暂停 |
| 魈公引擎：停止 | 停止并清空当前播放 |
| 魈公引擎：老板键 | 暂停 + 切走（默认 Ctrl+Shift+H） |

## 配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `xiaogong.speed` | 1.0 | 打字速度倍数 |
| `xiaogong.errorRate` | 0.012 | 每字符出错概率 |
| `xiaogong.seed` | 42 | 随机种子，决定节奏 |
| `xiaogong.thinkEveryLines` | 47 | 每多少行思考一次 |
| `xiaogong.driftEveryLines` | 420 | 每多少行走神一次 |
| `xiaogong.bossKeyTarget` | 空 | 老板键切走的网址或文件路径；空则关闭所有编辑器 |

## 节奏是怎么算的

```
基准      62ms / 字符（约每分钟 190~210 字符）
分布      对数正态（sigma 0.42），有长尾：大部分快，偶尔卡一下
语义      import 0.6× · def/class 1.8× · 注释 0.8× · 空行 0.15×
缩进      0.45×（缩进不需要思考）
标点      : 和 , 之后 1.5×；) ] 之后 1.25×
思考      每 47 行停 120~450ms
走神      每 420 行停 3~15 秒
错误      默认 1.2% 每字符；打错 → 停 0.3~1.5s → 退 1~4 格 → 重打
```

**同一种子，节奏完全可复现。**

## 三条安全保证

```
1. 只读     对源目录只用 readdir / stat / readFile，没有任何写入调用
2. 不联网   源码里没有 fetch / http / net
3. 不落盘   写入的是一个 untitled 文档，磁盘上不会出现 .py 文件
```

## 0.2.0 之后的行为说明

### 文件会一个一个出现

写到第几个文件，资源管理器里才出现第几个文件；写完了它就有内容，可以点开看。
这些文件存在内存里（虚拟文件系统 `xiaogong://`），**磁盘上不会多出任何 .py**。
停止播放后，虚拟目录整体移除。

### 速度不是线性的

| 速度 | 行为 |
|---|---|
| 0.1 ~ 20× | 逐字符写，能看到打错、退格、停顿——最像人 |
| 20 ~ 200× | 自动合并成 4 个字符一次写，仍然有停顿 |
| 200 ~ 1000× | 整行一次写，靠动画帧追，几十秒能写完一个项目 |

**高速时逐字符是假的**，因为 VS Code 的每次编辑都是跨进程调用，对着一行敲 40 个字符会卡。

### 停顿按全局行号算

第 47 行停一次思考、第 420 行走神一次——这个"第几行"是**跨文件累计**的，
不是每个文件从头数。所以播到第三个文件时，停顿位置依然是自然的。

### 存档可以和独立软件共用

两边都写在 `%APPDATA%\xiaogong\sessions`，扩展里存的进度，独立软件能接着播，反之亦然。
